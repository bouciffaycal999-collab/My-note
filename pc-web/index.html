CERAMICA POS — PC
Lancement recommandé via serveur local
Vous avez ouvert index.html directement (file://). Google Sign-In nécessite http://localhost.

Double-cliquez simplement sur Start_CERAMICA_PC.bat (Windows) ou lancez ./start_pc.sh (Mac/Linux) dans le dossier pc-web.

Ou exécutez dans un terminal : python -m http.server 8173 puis ouvrez http://localhost:8173.
